# LeetCode 高频面试题（Go）

按题型分类的 Go 刷题仓库，共 **144 题**、**15 个分类**。
覆盖 **LeetCode Hot 100** ∪ **面试经典 150 题** ∪ **codetop 高频** 并集。

每题一个独立 `.go` 文件：

- 文件顶部注释：LeetCode 题号、难度、面试频率、题目描述、多组示例、数据范围、思路提示、题目链接
- 文件内：与 LeetCode 一致的函数签名骨架（`// TODO: 实现`），以及必要的结构体定义
- `main()` 里预置了示例调用的测试桩

## 使用方式

单文件即可运行（无需 go.mod）：

```bash
# 语法检查
gofmt -l ./00-数组/p0001_two_sum.go

# 编译运行（先填实现，或删掉 main 里的调用桩）
go run ./00-数组/p0001_two_sum.go
```

每个文件都是完整独立的 Go 程序，互相不依赖。

## 刷题建议

1. 按目录顺序刷：数组 → 双指针 → 滑动窗口 → ... 由浅入深
2. 优先做 ★★★★★ 面试频率的题，这些是 codetop / Hot 100 的最高频
3. 实现前先读注释里的思路提示，写完后对照 LeetCode 提交验证
4. 5★ 题务必做到白板默写熟练（快排、二分模板、回溯模板、堆）
